# Maintainers

## Current Maintainers

The repository is maintained by the NVIDIA CSP GTM SA team.

## Escalation

Escalate repository access, release-readiness, or ownership questions to the
GitHub repository maintainers for `NVIDIA/nvidia-azure-samples`.

## Public Release Checklist

Before publishing this repository externally, maintainers should confirm:

- Named maintainers and backup maintainers are listed with public handles.
- CODEOWNERS entries point to valid GitHub or GitLab users or teams.
- The selected license has been approved for this project.
- Bundled media and presentation assets have documented provenance and
  redistribution rights.
- Third-party dependency notices are complete for the release vehicle.
